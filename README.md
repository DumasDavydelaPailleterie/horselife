# 二一之前

八個學期,每一次選擇都記在成績單和名單上。期末沒過就沒有下一頁。

大學四年的文字模擬。核心指標是「生涯人斬」,每發生一次一夜情計數加一。每個學期都有期末考,學力或肌力沒達到本學系的門檻就直接被退學,沒有補考。

介面採卷宗風格——整局遊戲呈現為一份學務處的個案檔案。相同的檔案編號加上相同的選擇會產生完全相同的一份檔案,所以可以把編號分享給別人重現同一個開局。

## 玩法

- **選學系**:外文系、數學系、資工系、法律系,各有不同的起始能力與期末考門檻。
- **技巧力從 1 開始**,不能用訓練骰子加點,只能靠遊戲中的實際經歷成長。每個系都藏著一位「老學長」,在大一階段的某個特定活動裡才遇得到,找到他就能一次獲得大量技巧力。每個系藏的地方不一樣。
- **每學期擲三顆骰**,每顆可以投入體力、學力、肌力,或換成社交活動場次。這是本作最核心的取捨:骰子都拿去換社交場次,人斬數會衝很快,但學力跟不上期末考就會被二一。
- **社交活動**決定你一個學期能接觸多少對象,高流量的活動(夜店、交友軟體)有能力門檻,也有較高的風險。
- **校內風評**會隨人斬數累積,風評越高,後續攻略的難度越高。

## 開發

需要 Node.js 18 以上。沒有任何外部套件依賴。

```bash
npm run serve
```

然後開 `http://127.0.0.1:5188/`。（ES 模組不能用 `file://` 協定直接開啟,所以開發時需要這個伺服器。）

執行單元測試:

```bash
npm test
```

執行自動模擬,產出平衡數據報告:

```bash
npm run sim
```

打包成單一 HTML 檔案(產出到 `docs/`):

```bash
npm run build
```

打包腳本會先檢查 `src/` 底下每一支 `.js` 都有列進打包清單,漏掉的話會直接失敗,不會產出壞掉的檔案。

## 專案結構

```
index.html          遊戲主頁面
src/
  rng.js            種子化隨機數
  data/
    config.js       所有平衡參數集中在此（調整平衡的唯一入口）
    depts.js        四科系起始能力與期末考門檻
    activities.js   社交活動表
    events.js       事件卡
    names.js        對象姓名池
    mentors.js      各系老學長
  core/             遊戲邏輯（完全不碰 DOM，可在 Node.js 裡單獨測試）
  ui/render.js      畫面渲染（唯一碰 DOM 的檔案）
tests/              單元測試
sim/
  serve.js          開發伺服器
  playthrough.js    自動模擬與平衡報告
  build.js          單一檔案打包
docs/               打包產物（GitHub Pages 從這裡發布）
```

邏輯層與畫面層完全分離,引擎採用狀態機而不是回呼結構,所以測試程式與真實畫面是用完全相同的方式驅動遊戲。

## 部署

GitHub Pages 的來源設定為 `main` 分支的 **`/docs`** 資料夾。

`docs/index.html` 是完全自給自足的單一檔案。之所以部署打包版而不是多檔案版,是因為 GitHub Pages 對每個檔案送出 `Cache-Control: max-age=600`,多檔案架構在更新後會有一段時間出現新舊模組混雜的狀態,瀏覽器會直接拋出 SyntaxError 變成白畫面。單一檔案不會有這個問題——快取到的一定是完整的舊版,不會是壞掉的混合體。

更新流程:

```bash
npm test && npm run build && git add . && git commit -m "說明改了什麼" && git push
```
